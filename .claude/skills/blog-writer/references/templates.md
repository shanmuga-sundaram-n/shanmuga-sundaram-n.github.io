# Post templates

Pick by intent. All share the front matter in SKILL.md.

## Opinion / thought leadership
1. Hook: the common assumption and why it bothered you
2. What I tried / measured (first-hand evidence)
3. The alternative and how it works
4. Cost / latency / risk comparison
5. Where it breaks (limits)
6. Decision rule

## How-to / tutorial
1. What you'll build and the end result (screenshot/diagram)
2. Prerequisites (versions pinned)
3. Steps, each: goal, code, expected output
4. Gotchas and debugging
5. Where to go next

## Case study
1. Context and constraints
2. The problem and what failed first
3. Decision and alternatives rejected (with reasons)
4. Implementation highlights
5. Results (numbers) and what you'd change
6. Lessons

## Comparison
1. The decision being made and criteria
2. Quick verdict table
3. One section per option: how it works, strengths, weaknesses
4. Head-to-head on each criterion
5. Recommendation by scenario

## Deep dive / explainer
1. Why it matters now
2. Mental model (diagram)
3. Internals, layer by layer
4. Worked example
5. Trade-offs and misconceptions
6. Takeaways
